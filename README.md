# エコーミラー

カメラ映像を「10秒前映像」として確認できる、フォームチェック用の軽量 PWA です。ダンス、整体、スポーツ練習などで、自分の動きを少し後から確認する用途を想定しています。

## 使い方

1. HTTPS で配信されたページを開きます。
2. 「カメラを開始」を押してカメラ権限を許可します。
3. 遅延時間を 2〜30 秒で調整します。
4. 必要に応じてミラー反転、カメラ切替、回転、全画面表示を使います。

## 古い iPad 向けの安定化

この版では、長時間利用で落ちたり映像が止まる問題を減らすために、以下を調整しています。

- `toDataURL()` の同期変換を避け、`toBlob()` で非同期にフレームを圧縮
- iPad 系ではキャプチャ解像度と保存 fps を控えめにして発熱とメモリ使用量を削減
- 古いフレームの Blob URL を破棄してメモリを解放
- バッファが遅延秒数まで溜まるまでは「準備中」と表示
- カメラ切替失敗時に現在のカメラを止めない

古い端末では高 fps よりも止まらないことを優先しています。映像が粗く感じる場合は、`index.html` の `CAPTURE_MAX_DIM` と `CAPTURE_INTERVAL` を調整してください。

## 配信

GitHub Pages でも Vercel でも静的サイトとして配信できます。カメラ API を使うため、原則 HTTPS が必要です。

### GitHub Pages

このリポジトリを Pages の公開元に指定すれば動きます。

### Vercel

Vercel にリポジトリを import し、Framework Preset は `Other` のままデプロイできます。ビルドコマンドは不要です。

`vercel.json` ではカメラ利用の Permissions-Policy と Service Worker 更新用の Cache-Control を指定しています。

## プライバシー

映像はブラウザ内で処理され、サーバーへアップロードしません。録画保存機能もありません。

## ファイル構成

- `index.html`: アプリ本体
- `manifest.webmanifest`: PWA 設定
- `sw.js`: オフライン用 Service Worker
- `vercel.json`: Vercel 配信用ヘッダー設定
